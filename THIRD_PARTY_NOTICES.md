# Third-party code and data

The Muon baseline in `experiments/revision/vendor/muon_official.py` is an
unchanged copy of [KellerJordan/Muon](https://github.com/KellerJordan/Muon) at
commit `f98f1cacc0263b04290753e32be8d498c1efc806`. Its MIT license and author
credits are preserved. The neighboring `provenance.json` records the source
commit and file checksum.

The paper source includes the ICML 2026 style files and their original notices.
Using this format does not indicate conference acceptance.

Datasets are downloaded separately and remain subject to their providers'
terms. The repository does not include datasets, pretrained weights, trained
checkpoints or service credentials.
